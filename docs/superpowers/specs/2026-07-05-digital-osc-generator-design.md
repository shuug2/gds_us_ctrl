# 디지털 OSC 제너레이터 — 신규 프로젝트 설계 (2026-07-05 브레인스토밍)

> **요약**: 현 프로젝트(gds_us_ctrl) 종료 후 착수할 **아날로그 발진보드+초음파 출력단의 디지털 제어 전환** 프로젝트의 승인된 설계. 결론 = **실현 가능**(상용 디지털 초음파 제너레이터의 표준 구조). 목적 = ① 아날로그 보드 의존 제거 ② 제어 품질·기능 향상 — 1차 기준선은 기존 거동 재현(용착 품질 동등성), 그 위에 정밀 공진 추적·텔레메트리 개선. 범위 = **단일 보드 완전 통합**(UI=DGUS LCD·통신=Modbus RTU/TCP 아키텍처는 기존 유지, OSC 코어 신규 설계, 주변부 필요 수정). 확정 결정 = 접근 A(**단일 STM32G474VE**, HRTIM ~0.2Hz/step) + **풀브리지 phase-shift**(진폭=펌웨어 파라미터, I2C_POT 소멸) + V·I 실측 센싱(6b의 상위 호환) + gen_core 순수 코어/글루 패턴 + 감시계층 포팅(순수 코어 무수정 이식, Modbus 0x00~0x1D 계약 불변). 정격 = **~1kW 1차, 대용량은 파워단 블록 교체로 확장**(A3). 개발 = Phase 0(B-SEAM 측정+트랜스듀서 임피던스 특성화 — 현 프로젝트 벤치와 겸행) → 1 보드 설계 → 2 로직부 브링업(기존 회귀 게이트) → 3 파워단 더미 부하 → 4 실 혼 rig A/B → 5 통합 E2E. 최대 리스크 = 트랜스듀서 파라미터 미확보·실부하 추적 안정성. **다음 단계 = 프로젝트 착수 시 신규 repo에서 Phase 0 데이터를 갖고 writing-plans**(§12).

## 0. 배경 · 목적 · 범위

- **배경**: 현 시스템은 MCU가 초음파 주파수를 직접 만들지 않고 외부 아날로그 발진보드에 위임한다(채널 ON/OFF·진폭 I2C_POT·피드백·SEEK/RESET만 담당 — `docs/superpowers/analysis/2026-06-20-bseam-osc-signal-chain-and-port-fidelity.md` §1). 이 발진보드+출력단을 디지털 제어로 대체한다. 발진보드는 **완전 신규 설계**(현재 제어 방법은 참고 자료).
- **목적** (사용자 확정, 우선순위 기준):
  1. **아날로그 보드 의존 제거** — 자체 설계 확보. 1차 기준선 = 기존 거동 재현(용착 품질 동등성).
  2. **제어 품질·기능 향상** — 정밀 공진 추적, 진폭 폐루프, 주파수/위상/전력 텔레메트리.
- **범위** (사용자 확정): **단일 보드 완전 통합**. UI(DGUS LCD)·통신(Modbus RTU/TCP, W5500, RS-485) 아키텍처는 기존 유지, OSC/출력단은 신규 설계, 필요한 주변부는 기존에서 수정.
- **정격** (사용자 확정): **~1kW 1차 개발 완료 후 대용량 설계 예정** → 파워단을 교체 가능한 블록으로 경계 설정.
- **비목표**: 타주파수(20k/28k/40kHz) 제품군 대응은 이번 범위 아님(단, 주파수는 펌웨어 파라미터화로 여지만 확보 — A2).

## 3. 시스템 아키텍처 (섹션 1 — 승인)

### 3.1 블록 구성

```
 [AC 220V 단상] ─ EMI 필터 ─ 정류 ─ DC 버스(~310V) ┐
                                                    │
        ┌── 게이트 드라이버(절연) ── 풀브리지 4-SW ──┤
        │                              │
 STM32G474VE                    출력 트랜스 ─ 정합 인덕터 ─ [트랜스듀서 34.46kHz]
  ├ HRTIM(PWM+FAULT)                   │
  ├ COMP/ADC ◄── 전류 CT · 전압 센싱 ◄─┘   (위상=비교기, 크기=ADC)
  ├ USART ── DGUS LCD            ← 기존 유지
  ├ SPI   ── W5500 (Modbus TCP)  ← 기존 유지
  ├ USART ── RS-485 (Modbus RTU/mon) ← 기존 유지
  ├ I2C   ── FRAM                ← 기존 유지 (I2C_POT 소멸 — 진폭은 내부 폐루프)
  └ GPIO  ── 물리 IO(START/RESET/EMSW/SOL 등) ← 기존 유지
```

핀맵은 신규(핀 역할은 기존 승계). 정확한 핀 배치는 보드 설계(Phase 1)에서 확정.

### 3.2 절연 · 접지

- 게이트 드라이브 절연(절연 드라이버 또는 부트스트랩+절연 하이사이드 — Phase 1 확정), CT 자체 절연, 전압 센싱 = 분압+절연 증폭 또는 트랜스 보조권선.
- 로직부(MCU/LCD/통신)·파워부 GND 분리 전략 = Phase 1 확정. LCD·RS-485·이더넷 외부 인출 → 로직부는 안전 접지 기준.
- 계측 안전 = B-SEAM 준비물 승계(차동/절연 프로브, 저전압·최소 진폭 우선).

## 4. 파워단 (섹션 2 — 승인)

| 항목 | 설계 | 비고 |
|---|---|---|
| 토폴로지 | 풀브리지 + phase-shift 변조 (D3) | 진폭 = 위상천이각 |
| 스위칭 소자 | 650V Si super-junction MOSFET | 34.5kHz는 SMPS 기준 저속 — SiC 불요 |
| 출력 트랜스 | 페라이트 승압 | **권선비 = Phase 0 임피던스 측정 종속** |
| 정합 | 직렬 인덕터로 트랜스듀서 C0 보상 | 값 = Phase 0 종속, 트랜스 누설 인덕턴스 합산 설계 |
| DC 버스 | 정류 + 벌크 캡 + 돌입 제한(NTC/릴레이) + 방전 저항 | ~310VDC |

브리지 출력은 구형파지만 정합 L + 트랜스듀서 공진 특성이 대역 필터 역할 → 트랜스듀서에는 준정현 전류(상용기 동일 방식).

## 5. 센싱 — 각 신호 2경로 (D5)

- **전류**: CT → ① 비교기(제로크로스 → 위상 검출) ② OPAMP+ADC(RMS/피크 → 진폭 폐루프·overload)
- **전압**: 트랜스 보조권선 또는 분압 → 동일 2경로
- **전력/에너지 = V·I 실측 연산**(CORDIC/FMAC) — 표시(curr_power/curr_energy)와 weld 에너지 종료 입력이 실측 기반이 됨.

## 6. 제너레이터 코어 펌웨어 (`gen_core`, 섹션 2 — 승인)

상태머신 (순수 코어, host-test):

```
OFF → SWEEP(=SEEK: 파라미터화 스윕[시작/끝/속도] → 제로위상/최대어드미턴스 lock)
    → TRACK(=RUN: 위상 PI 루프 ~1kHz로 공진 추종, phase-shift로 진폭 폐루프)
    → FAULT(과전류/주파수 창 이탈/과부하)
```

- 파형 생성: HRTIM master 주기 = 구동 주파수, phase-shift = 진폭, dead-time 하드웨어.
- 위상 검출: 전류 제로크로스 비교기 → 타이머 캡처 → 전압 기준과의 위상차 → PI → 주파수 보정.
- 통신/LCD가 아무리 바빠도 파형 생성·보호는 하드웨어 레벨(D4) — 슈퍼루프 비의존.

### 6.1 기존 의미론 이식 접점 (감시계층 무수정, hook만 실체화)

| 기존 (gds_us_ctrl) | 신규 실체 |
|---|---|
| `app_seek_reset` hook stub | gen_core SWEEP/RESET 명령 (500ms 자동 체인 의미론 유지) |
| `app_reg` RUN 게이트 + warm-up 램프 | gen_core enable + soft-start 진폭 램프 |
| I2C_POT (`pot_dac_from_power`) | output_power % → 목표 motional 전류 매핑 (폐루프) |
| overload ×5 디바운스 → SEEK 복구 | 2계층: HW 사이클 차단(COMP→HRTIM FAULT) + SW 판정·복구 체인 이식 |
| weld 에너지 종료 (`reg_energy_from_acc`) | 실측 V·I 적산 입력으로 대체 |

### 6.2 텔레메트리 (목적 ② 반영)

실 주파수/위상/전력/버스 전압 → Modbus **기존 맵(0x00~0x1D) 뒤 신규 주소로 추가**. 기존 계약 불변 → HMI 하위호환. 레지스터 추가 시 HMI 계약 문서 §3 갱신 절차 준수.

## 7. 감시계층 포팅 전략 (섹션 3 — 승인)

- **무수정 이식(순수 코어)**: `app_weld_fsm` / `app_seek_reset_fsm` / `app_input_fsm` / `app_reg_calc`·`reg_energy` 계산 / Modbus core·MBAP / LCD 프로토콜 로직 — **host-test 스위트째 이식**.
- **재작성(글루/드라이버)**: `board.c`(핀맵 신규) / `clock.c`(G474 170MHz) / drivers(usart/tim/spi/i2c → G4 HAL) / `periph.c`. vendor = G4 HAL in-tree 카피(기존 방식 유지).
- **계약 유지**: DGUS LCD 자산·변수 주소 그대로 / Modbus 0x00~0x1D 불변 / HMI(gds_us_hmi) 무수정 호환.

## 8. 개발 단계

| Phase | 내용 | 게이트 |
|---|---|---|
| **0. 측정** | B-SEAM 측정(아날로그 보드 스윕 프로파일 = 거동 사양서) + **트랜스듀서 임피던스 특성화(C0/motional R-L-C)** + 정격 실측(입력 전력) + 기존 발진보드 회로 역해석 | **현 프로젝트 벤치 세션과 겸행 가능** (준비물 동일: 절연 프로브·실 혼 rig) |
| **1. 보드 설계** | KiCad 회로/PCB — 로직부 = 현 hw 참조, 파워단 신규. 게이트드라이브·센싱은 가능하면 소형 시제 선검증 | **임피던스 데이터 없이 정합값 확정 금지** |
| **2. 로직부 브링업** | 포팅 펌웨어로 기존 기능 재현(LCD/Modbus/물리IO), 파워단 미배선 | 기존 host 스위트 + HW 회귀 항목 전부 PASS |
| **3. 파워단 브링업** | 더미 부하(Phase 0 파라미터로 만든 RLC 등가), 저버스전압부터 승압 | 파형·보호(FAULT 차단)·진폭 제어 검증 |
| **4. 실부하** | 실 트랜스듀서/혼 rig — 스윕/lock/추적/soft-start/overload. **기존 아날로그 시스템과 같은 혼으로 A/B 비교** | 공진 추적 안정성 |
| **5. 통합 E2E** | weld 사이클 + LCD/Modbus/HMI + 용착 품질 동등성(사용자 판정) | 목적 ①② 달성 |

## 9. 테스트 전략

- `gen_core` = host-test(스윕/lock 판정/PI/상태 전이) — 현 프로젝트 패턴.
- 파워단 = 더미 부하 벤치(RLC 등가 — Phase 0 측정 파라미터로 제작).
- 회귀 = 기존 host 스위트 + 기존 HW 검증 항목 목록 재사용(Phase 2 게이트).
- 안전 = 각 Phase에서 절연 프로브·저전압 우선·최소 진폭 규칙(B-SEAM 안전 수칙 승계).
